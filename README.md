# france-Bus-in-Doubs
ProchainBus is a web application displaying upcoming bus departures across the Doubs and Belfort regions in France, featuring an interactive interface, multiple cities and stops, and an E-Paper inspired display.

# 🚌 ProchainBus Région (25 & 90)

**ProchainBus** is a web application designed to display upcoming public transport departures across the Doubs (25) and Territoire de Belfort (90) regions in France.

The project features a modern interface inspired by real-world E-Paper bus stop displays, providing a clear and accessible overview of upcoming bus departures, destinations, line numbers and estimated waiting times.

## ✨ Features

- **City Selection:** Browse multiple cities across the region.
- **Bus Stop Selection:** Select available bus stops based on the chosen city.
- **Upcoming Departures:** Display the next three scheduled bus departures.
- **Detailed Information:** View line numbers, destinations, waiting times and service statuses.
- **Automatic Refresh:** Automatically refresh displayed information every 30 seconds.
- **Manual Refresh:** Update the interface using the dedicated refresh button.
- **E-Paper Simulation:** A virtual display inspired by electronic bus stop information screens.
- **Responsive Design:** Optimized for desktop and mobile devices.

## 🚀 Getting Started

### Installation

1. Open the project folder.
2. Launch `index.html` in your web browser.

No additional dependencies or installation steps are required to run the interface.

## 🎯 Project Goals

The goal of ProchainBus is to explore web development and create a simple, accessible public transport information interface.

It also serves as an experimental project for simulating an embedded information display system, similar to the E-Paper screens found at real-world bus stops.

## ⚠️ Project Status

This project is currently experimental. Bus departure information is based on locally stored sample data, while the transport API connection is being explored for potential future integration.
